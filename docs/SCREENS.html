PFMEA Import 파서 — FC시트 FM:FC N:1:N 매핑 수정
FC시트에서 하나의 고장형태(FM)에 여러 고장원인(FC)이 연결될 때 마지막 FC만 저장되는 문제를 해결하여 고장사슬이 누락 없이 Import되게 한다.
1) 넥센 샘플 엑셀(FC 214행)로 재현 → FM 38건 중 11건에서 FC 누락 확인
2) excel-parser.ts의 FM 키 dedup 로직을 Map<FM, FC[]> 누적 방식으로 변경
3) 동일 파일 재Import 후 DB 건수 비교
사실 확인함 (기록자 본인이 내용을 확인·수정)
FC 누락 11건 → 0건. 단, FC 셀이 빈 행 3건에서 예외 발생(실패). 해당 행은 Import 제외됨.
사실 확인 필요 — 체크 전 제출 불가
N:1:N 누적 방식으로 주요 문제 해결. 빈 FC 셀 처리는 미해결 — 내일 예외처리 추가. 대안(FC를 별도 시트로 분리)은 고객 양식 변경이 필요해 채택하지 않음.
